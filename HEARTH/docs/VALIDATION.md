最终执行 `python -m coverage run --source=hearth -m pytest -q`：**57 passed in 12.22s**。748 条可执行语句中的 641 条由该测试进程覆盖，覆盖率为 86%。`engine.py` 96%、`models.py` 97%、`simulator.py` 100%；CLI 子进程的运行不计入这份覆盖率。

## Playwright 视觉检查

真实 Chromium 渲染，在 1440×1000、390×844、320×768 三种视口测试 normal、outage、sensor_fault。三项均通过：操作区无重叠，控件高度不少于 44px，无横向溢出，无未捕获 JavaScript 错误，曲线与状态事件正常显示。桌面及窄屏截图已人工检查；窄屏坐标字号问题修订后再次测试。

当前环境的浏览器策略拒绝访问 loopback，原生 `page.goto` 返回 `ERR_BLOCKED_BY_ADMINISTRATOR`。因此本次使用脚本的 `--bridge` 模式：Playwright 渲染本地 HTML/CSS/JS，页面触发的请求由 Python 转发给实际启动的 FastAPI HTTP 服务。该结果覆盖页面渲染、交互和后端响应；**不覆盖原生浏览器网络、CSP 执行或浏览器存储行为的完整端到端链路**。API 响应中的 CSP 等安全头另由 TestClient 检查。默认脚本保留原生模式，需在正常浏览器环境重跑。
