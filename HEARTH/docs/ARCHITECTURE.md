# 实现架构与后续任务

依据：用户提供的 `HEARTH_我的任务清单与提示词.md`（T01–T18）和 `HEARTH_提案_中文翻译.md`。以下明确区分本次代码、材料中的设想和新增设计决策。

## 运行边界

本次使用 Python 3.13、FastAPI、Pydantic 和 SQLite。SQLite 存放本地原始读数、状态、追加事件与待发送记录；单个事务同时提交这些数据。一个进程负责一个网关信任域，默认仅监听本机。云端不参与状态转移。服务在有电且进程正常运行时，通过每秒 watchdog 检查离线和截止时间；完全断电时需要另行配置 UPS、设备端固件和执行器故障指示。

数据模型区分批次、设备和摊位。多个设备属于同一批次；设备重分配要求旧批次关闭。旧批次不会被新货覆盖，旧批次迟到的数据只追加到历史。更换批次始终从“尚无可用传感器”的黄灯状态开始。

模块职责：`models.py` 定义契约与配置；`physics.py` 计算温度动力学；`engine.py` 执行唯一的本地状态决策；`store.py` 保证事务、台账和重试；`simulator.py` 产生独立合成对照；`api.py` 提供鉴权入口；`cli.py` 启动演示与服务。页面使用同源 HTML/CSS/JS，无第三方 CDN。

## 时间、单位与缺测

累积暴露为参考温度等效小时：

```math
r(T)=Q_{10}^{(T-T_{ref})/10},\quad \Theta=\int r(T(t))\,dt.
```

`SL_ref - Θ` 的单位为参考温度等效小时。假定未来温度恒定为 `T_future` 时，实际时钟剩余小时为：

```math
RUL(T_{future})=\frac{\max(0,SL_{ref}-\Theta)}{r(T_{future})}.
```

当前温度缺失或有节点异常时返回 `remaining_hours=null`。历史暴露持续累积：在读数有效期内做因果 sample-and-hold，超过有效期使用配置温度域上界作为保守演示外推，并显示健康异常。这个上界不构成对真实未知环境的物理保证。

Arrhenius 使用 Kelvin。`Ea = R ln(Q10)/(1/Tref,K - 1/(Tref,K+10))` 只在指定参考温区匹配 Q10，两种形式没有全温区精确等价关系。离线历史积分采用速率的梯形积分；在线决策不使用未来温度。

时间戳必须包含时区并归一化为 UTC。网关判断使用自身时钟；允许少量设备正时钟偏差，但不会把网关状态推进到未来。新鲜但略有传输延迟的读数可以更新当前观测，先前已经积分的时间不会回退。过旧、乱序、旧批次数据保留为历史，不参与实时状态重算。

## 三色及健康状态

健康状态独立于颜色。启动无数据、缺测、超时、故障、饱和、模型温度域外输入都无法产生绿灯。原型要求同一批次全部已登记节点健康后才能显示模型绿灯；后续可靠性加权或 quorum 必须通过实测验证。

批次硬截止或品质预算耗尽立即锁红，不等待 VOC 上升和多数表决。一般低品质预警需配置次数的新读数确认；重复事件与 watchdog 不增加确认数。红灯不会自行恢复。授权关闭批次产生追加事件，保留红灯记录；关闭状态与绿灯不同。

未知安全状态下，系统保持 `sale_allowed=false`。未来将食品安全审核、品质分级与促销资格分别建模，避免一个品质分数同时承担三种职责。

## 数据、权限和审计

事件 UUID 及 `(device_id, boot_id, sequence)` 双重唯一。完全相同的重传只返回 duplicate，内容不同的碰撞返回 409。批量请求全成功或全回滚。传感器必须符合已登记的市场/摊位/批次/设备绑定、单位和物理范围。

读取、写入传感器、注册或关闭批次分别使用不同随机角色凭证。当前为本地单信任域，不具备多租户逐用户 RBAC。后续远程部署需要 mTLS、设备凭证轮换、操作员身份、反向代理请求超时、速率限制与权限审计。

哈希链使用明确的 `hearth-json-v1` 编码。SQLite 触发器阻止应用层修改/删除，但数据库管理员仍能重写文件；没有外部链头锚定时，内部一致的尾部截断无法被仅靠链自身识别。`verify(expected_head=...)` 为外部检查点预留验证能力。本次没有假称防篡改绝对保证。

上行语义为“至少一次发送 + 下游按事件 hash 幂等处理”。远端成功但本地确认前崩溃会重发，测试明确覆盖此情形。实际 MQTT/TLS 传输尚未实现，`Store.deliver(sender)` 是已验证的传输边界。发送方必须设置网络超时，每个网关只运行一个发送 worker。容量达到配置上限时拒绝新读数，避免覆盖未发送事件；生产仍需独立磁盘容量告警与归档策略。
